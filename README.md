# Projekt-MVC
Zawartość projektu aplikacji pogodowej:
  Plik app_config.py (weather_app/config/app_config.py) - Plik zawieający dane konfiguracyjne okna aplikacji oraz API.
  Pliki źródowe w strukturze MVC (weather_controller.py, weather_model.py, weather_view.py) - główne pliki źródłowe aplikacji.
  Plik history_model.py - Przygotowany w celu rozwoju aplikacji o dalsze funkcje, zawiera kod tworzący i zapisujący listę          wyszukiwanych miast.
